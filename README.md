# WildFly Dependency Upgrades

Daily report of possible dependency upgrades in [WildFly](https://github.com/wildfly/wildfly), [WildFly Core](https://github.com/wildfly/wildfly-core) and other related projects, published at https://rhusar.github.io/wildfly-dependency-upgrades/.

Reports are generated by [Maven Dependency Updater](https://github.com/jboss-set/maven-dependency-updater) against a shallow checkout of each project's configured branch.
For every managed dependency the report lists the latest micro, minor and major upgrade.
The projects are listed in [config-projects.json](config-projects.json): `name` together with `branch` must be unique as they are used for the report file name, `scm` is the Git clone URL, and `branch` is optional (defaults to the repository's default branch).
Only final releases are considered, see [config-dependency-updater.json](config-dependency-updater.json).

[Report.java](Report.java) is a [JBang](https://www.jbang.dev/) script that collects the upgrades and renders the [Qute](https://quarkus.io/guides/qute-reference) templates in [templates](templates) into `target/site`.
The [workflow](.github/workflows/report.yml) runs it daily and publishes `target/site` to the `gh-pages` branch.

## Running locally

```bash
jbang Report.java
open target/site/index.html
```
